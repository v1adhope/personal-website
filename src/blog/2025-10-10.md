Language tooling is one of the important things to consider when picking a programming language. Official LSP that supported all general features and was compatible with popular text editors/IDEs. The library of linters is a treasure to avoid common mistakes and bugs. Well-designed package manager to manage (not struggle) dependencies. Background code checker to run tests automatically - change, build, execute
