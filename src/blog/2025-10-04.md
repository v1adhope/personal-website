I've used sway, hyprland, and aerospace. There are tiling managers, a non-classic style of window organization. Hyprland is the best Linux Wayland compositor with a large native module ecosystem (hypridle, hyprlock, hyprpaper, xdph), cool animations, and bug-free. Aerospace is an alternative for macOS with a few bugs and not a good UX. The value of these tools is that you can focus on the main action. Windows always fills the free space on the screen or shares it with others by default, which is half. Forget about moving windows, resize one, then the second. They're scaling automatically. Customizable workspaces, each application might know where to live
