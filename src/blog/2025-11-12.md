title: "Should null exist in a programming language?"
pubDate: 2025-11-12
description: "My perspective on null handling, built-in options, and safety."
tags: ["programmingLanguages"]
---

Should null exist in a programming language? The short answer is no.

I've run into a few situations that explain my perspective:

- Cowboys can't decide which approach to use: a null object or classic null handling.

- Ten levels of nested null checks.

- A mess in the end. Code checkers warn about a possible null reference, but the value will never actually be null.

- Built-in option types offer a balance. It's about safety: a value is either present or absent. You don't need other states.
