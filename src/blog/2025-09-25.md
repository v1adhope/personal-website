Golang is a messy language. Weak to write rich domain

- No ability to lock dependencies. When you try to update all with `go get -u`, you can’t lock specific
- No built-in options. Use references, or implement a lot of boilerplate code yourself
- Poor package and scope design
    - Why is your package calling `httpserverv2`? It's a standard and often unreadable
    - How do you store code in one package if it’s large? No way, suffer
- No official project layout. People usually write everywhere, like they want
- No built-in constructors, at least static methods. Common function names like `MySuperCumbersomeStructModelToRequest` don't have a bounding to a type
- No aliases/ sugar to return zero values and to handle `err != nil`
- Simplicity isn't a good way. Its lack of features
