---
title: "Effective Task Delegation in Programming"
pubDate: 2026-01-29
description: "Make a point and delegate tasks properly without micromanagement."
tags: ["programming"]
---

Don’t do decomposition for others unless the problem truly requires a complete, any good enough solution. Doing so is micromanagement, inefficient, and ruins the experience. There’s no creativity in it - an AI agent can do that job

In example:

- Hey, we’ve got a task to reach 30% of something this quarter. I need you to write an endpoint that gives me A, B, and C. It should be REST, as always, and able to fetch N entries. I don’t care how - just do it

- Consider it done

- Hey, we’ve got a task to reach 30% of something this quarter. ... Use this library. Name this ACB, not ABC. Do it through array, not map. Use pattern A, not B. Use :? instead of if (..) { ...}. Remove this }. Move this part in the middle of the file

- Why don't you do it yourself?

Make a point and delegate task properly
