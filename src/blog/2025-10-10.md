tags: ["developerTools", "programmingLanguages"]
---

Language tooling is one of the important things to consider when picking a programming language. Look for:

- An official language server that supports all the common features and is compatible with popular text editors and IDEs.
- A collection of linters to help avoid common mistakes and bugs.
- A well-designed package manager to manage dependencies without a struggle.
- A background code checker to run tests automatically: change, build, execute.
